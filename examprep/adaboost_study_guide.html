StatQuest — AdaBoost

AdaBoost, clearly explained

Adaptive Boosting builds a strong classifier from many weak ones (decision stumps), by iteratively focusing on the hardest examples.

The 3 core ideas

1. Use a forest of stumps, not trees

AdaBoost uses decision stumps — trees with only one split (one question). Each stump is a weak learner, slightly better than random chance.

2. Stumps have different amounts of say

Unlike Random Forests where all trees vote equally, each AdaBoost stump gets a weight called Amount of Say based on how accurate it is. Better stumps get more influence.

3. Stumps are made sequentially, errors inform the next

Each stump is built knowing what the previous one got wrong. Misclassified samples get higher weights, so the next stump focuses more on them.

Deep dives
Building the first stump — Gini index

AdaBoost evaluates all possible features and picks the stump with the lowest Gini impurity as the first weak learner.

Gini = 1 − Σ(pᵢ)²

A Gini of 0 = perfect purity (all same class). A Gini of 0.5 = maximum impurity (50/50 split).

The stump with the lowest weighted Gini impurity (using sample weights) is selected as the first weak learner.
Amount of Say (α) — stump influence weight

After a stump is built, we compute how much it should influence the final prediction:

α = ½ × log( (1 − Total Error) / Total Error )

Total Error = sum of weights of misclassified samples. For the first stump, all weights start at 1/N.

Drag Total Error to see Amount of Say change:
Error: 0.30
α = 0.42
Good classifier — has positive say
When error = 0.5 (random guessing), α = 0. When error > 0.5, α goes negative — AdaBoost can still use it by flipping its prediction!
Updating sample weights

After each stump, weights are updated so the next stump pays more attention to hard cases.

Misclassified: new w = w × e^α ↑ higher
Correctly classified: new w = w × e^(−α) ↓ lower

Then all weights are normalized so they sum to 1. Visualize 8 samples, α = 0.42:

Normalization ensures the weights always sum to 1, so they can be used as probabilities when resampling the dataset for the next stump.
Making final classifications

Each stump votes for a class, weighted by its α. The final prediction is the class with the highest total α-weighted votes.

→ Final prediction: YES (sum of α: YES = 0.68, NO = 0.32)
Unlike a simple majority vote, stumps with higher accuracy (higher α) count more — a single great stump can outweigh several mediocre ones.

AdaBoost is a boosting method — it converts many weak classifiers into one strong one. Random Forests use bagging to reduce the variance of strong classifiers.
The AdaBoost algorithm — step by step
1. Initialize sample weights: w = 1/N
2. Find best stump using weighted Gini
3. Compute Total Error = Σw of misclassified
4. Compute α = ½ log((1−ε)/ε)
5. Update weights: ↑ misclassified, ↓ correct
6. Normalize weights to sum to 1
7. Repeat from step 2 until done
8. Final class = sign(Σ αₜ × hₜ(x))
