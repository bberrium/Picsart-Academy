What is Gradient Boost?
Gradient Boost is an ensemble method that builds many small decision trees sequentially, each one correcting the errors of the previous. It is one of the most widely used algorithms for tabular data, powering many winning solutions in machine learning competitions.
Gradient Boost vs. AdaBoost
AdaBoost
Builds stumps (1-split trees). Each stump has a different amount of say. Adjusts sample weights after each stump.
Gradient Boost
Starts with a single leaf (the mean). Builds trees up to 8–32 leaves. Scales every tree by the same learning rate.
Key terms at a glance
Pseudo-residualObserved − Predicted (the error to fix)
Learning rate (ν)Scales each tree's contribution (0 to 1)
Number of leavesControls tree size; typically 8–32
Log(odds)Initial prediction for classification
Logistic functionConverts log(odds) → probability
Part 1 of 4
Gradient Boost for Regression — main ideas
These are the conceptual steps Josh Starmer walks through before introducing the math. The goal is to build intuition.
Algorithm steps (regression)
1
Make an initial prediction. The first "tree" is a single leaf that outputs the average of all target values. This is the starting point for every sample.
2
Compute pseudo-residuals. For each sample, calculate the difference between the observed value and the current prediction. These residuals capture what the model got wrong.
3
Fit a small tree to the residuals. Build a regression tree (capped at 8–32 leaves) using the original features, but with residuals as the target. When multiple samples land in the same leaf, use their average residual as the leaf's output value.
4
Update the prediction using the learning rate. The new prediction for each sample is the old prediction plus the learning rate times the tree's output for that sample.
New prediction = prev. prediction + ν × (tree output)
The learning rate keeps steps small to avoid overfitting.
5
Repeat. Compute new residuals from the updated predictions and build another tree. Continue until you hit the maximum number of trees or residuals stop shrinking meaningfully.
Why does the learning rate help?
Friedman's original paper showed that taking many small steps — rather than one big step — leads to better generalization on test data. A low learning rate reduces variance at the cost of needing more trees. Typical values: 0.05–0.1.
Part 2 of 4
Gradient Boost for Regression — the math
Part 2 dives into the formal algorithm. The loss function used is squared loss. Residuals turn out to be the negative gradient of this loss, which is why the algorithm is called "gradient" boost.
Why are residuals the gradient?
The squared loss is: L = ½(y − F)²

Its negative gradient with respect to the prediction F is:
−∂L/∂F = y − F = the residual
So fitting each new tree to the residuals is exactly performing gradient descent in function space.
Formal algorithm (Friedman, 1999)
F₀
Initialize. Find the constant γ that minimizes the total loss. For squared loss, this is the mean of y.
F₀(x) = argminᵧ Σ L(yᵢ, γ) = mean(y)
2-1
Compute pseudo-residuals for each sample at step m:
rᵢₘ = −[∂L(yᵢ, F(xᵢ)) / ∂F(xᵢ)] = yᵢ − Fₘ₋₁(xᵢ)
2-2
Fit a regression tree to the pseudo-residuals. This creates J terminal regions Rⱼₘ (leaves).
2-3
Find the optimal output value for each leaf j. For squared loss this is simply the average of the residuals that fall into that leaf:
γⱼₘ = mean of rᵢₘ for xᵢ ∈ Rⱼₘ
2-4
Update the model. Add the new tree scaled by learning rate ν:
Fₘ(x) = Fₘ₋₁(x) + ν · Σⱼ γⱼₘ · 1(x ∈ Rⱼₘ)
Final prediction
F_M(x) = F₀(x) + ν·tree₁(x) + ν·tree₂(x) + … + ν·treeM(x)
The prediction accumulates contributions from ALL trees. Because each tree corrects the errors left by the previous ones, the combined model progressively fits the training data more closely.
Part 3 of 4
Gradient Boost for Classification — main ideas
Classification follows the same broad structure as regression, but works in log-odds space instead of raw value space. Predictions are then converted to probabilities through the logistic function.
Key difference from regression
Regression
Initial leaf = mean(y). Residuals = y − predicted value. Leaf output = average of residuals.
Classification
Initial leaf = log(odds). Residuals = observed − predicted probability. Leaf output uses a special formula.
Algorithm steps (classification)
1
Initialize with log(odds). Count the positives (class = 1) and negatives. The initial prediction for all samples is:
log(odds) = log( #positives / #negatives )
Convert to probability with the logistic function: p = eˡᵒᵍ⁽ᵒᵈᵈˢ⁾ / (1 + eˡᵒᵍ⁽ᵒᵈᵈˢ⁾)
2
Compute pseudo-residuals. For binary classification with log-loss:
rᵢ = Observed − Predicted probability = yᵢ − pᵢ
These residuals range from −1 to +1.
3
Fit a regression tree to the residuals. Even though this is a classification problem, the residuals are continuous, so we use a regression tree. Limit leaves to 8–32.
4
Compute leaf output values. The raw leaf average can't be used directly because predictions live in log-odds space while residuals live in probability space. Use:
γⱼ = Σ residuals / Σ [pᵢ(1 − pᵢ)]
where the sum is over all samples in that leaf.
5
Update log(odds) prediction:
log(odds)_new = log(odds)_old + ν × γⱼ
Convert to probability with logistic function for the next residual calculation.
6
Repeat until max trees reached. Final probability is produced by converting the accumulated log-odds through the logistic function, then comparing to a threshold (usually 0.5).
Part 4 of 4
Classification — the math behind leaf values
Part 4 derives why the leaf output formula uses a second-order Taylor expansion. This is the "hard part" — but the intuition is that we can't simply average probability-space residuals when predictions are in log-odds space.
The problem with plain averaging
In regression, the optimal leaf value is the mean of residuals — easy. In classification, the residuals are in probability space, but adding them to the prediction happens in log-odds space. A direct average would be mathematically inconsistent. We need to find the γ that minimizes the log-loss for each leaf.
Deriving the leaf output formula
1
The loss function for classification is log-loss (cross-entropy):
L = −[y·log(p) + (1−y)·log(1−p)]
2
We want to find γ (leaf output, added to log-odds) that minimizes this loss. Taking the second-order Taylor expansion around the current prediction and solving gives:
γⱼ = Σᵢ residuals / Σᵢ [pᵢ(1 − pᵢ)]
The denominator is the sum of variances of the predicted probabilities in that leaf.
3
Intuition: When the predicted probability is near 0 or 1, pᵢ(1−pᵢ) is small — meaning the model is already confident. Those samples get less influence on the leaf update. When pᵢ ≈ 0.5 (uncertain), pᵢ(1−pᵢ) ≈ 0.25 — those samples pull harder.
Full classification algorithm summary
Step 1: F₀ = log(odds) = log(#pos / #neg) Step 2: rᵢ = yᵢ − sigmoid(Fₘ₋₁(xᵢ)) [pseudo-residuals] Step 3: Fit regression tree → leaves R₁…Rⱼ Step 4: γⱼ = Σ rᵢ / Σ [pᵢ(1−pᵢ)] [leaf values] Step 5: Fₘ = Fₘ₋₁ + ν·Σⱼ γⱼ·1(x∈Rⱼ) [update log-odds] Step 6: p_final = sigmoid(F_M(x)) Step 7: class = 1 if p_final ≥ 0.5 else 0
Key insight: same structure, different loss
The beauty of Gradient Boost is that the overall algorithm is identical for regression and classification. What changes is only the loss function and the resulting leaf-value formula. You can swap in any differentiable loss and the framework still works — this is why libraries like XGBoost and LightGBM can handle so many problem types.
