What is Gradient Boost?
Gradient Boost is an ensemble method that builds many small decision trees sequentially, each one correcting the errors of the previous. It is one of the most widely used algorithms for tabular data, powering many winning solutions in machine learning competitions.
Gradient Boost vs. AdaBoost
AdaBoost
Builds stumps (1-split trees). Each stump has a different amount of say. Adjusts sample weights after each stump.
Gradient Boost
Starts with a single leaf (the mean). Builds trees up to 8–32 leaves. Scales every tree by the same learning rate.
Key terms at a glance
Pseudo-residualObserved − Predicted (error to correct)
Learning rate (ν)Scales each tree's contribution (0–1)
Number of leavesControls tree size; typically 8–32
Log(odds)Initial prediction for classification
Logistic functionConverts log(odds) → probability
Part 1 of 4
Gradient Boost for Regression — main ideas
The conceptual walkthrough before the math. Goal: build intuition for how a sequence of trees progressively corrects errors.
Algorithm steps (regression)
1
Make an initial prediction. The first "tree" is a single leaf that outputs the average of all target values. This is the starting prediction for every single sample.
2
Compute pseudo-residuals. For each sample, calculate the difference between the observed value and the current prediction. These capture exactly what the model got wrong.
residual = observed − predicted
3
Fit a small tree to the residuals. Build a regression tree (capped at 8–32 leaves) using the original features but with residuals as the target. When multiple samples share a leaf, use their average residual as the leaf output.
4
Update prediction using the learning rate.
New prediction = prev. prediction + ν × (tree output)
The learning rate ν scales down each tree's contribution to prevent overfitting.
5
Repeat. Compute new residuals from updated predictions, build another tree. Continue until reaching the max number of trees or residuals stop shrinking meaningfully.
Why does the learning rate help?
Friedman's original paper showed empirically that many small steps generalize better than a few large steps. A low ν reduces variance on the test set — at the cost of needing more trees. Typical values used in practice: 0.05–0.1.
Part 2 of 4
Gradient Boost for Regression — the math
Part 2 derives the formal algorithm. The loss function is squared loss. The key insight: residuals are the negative gradient of this loss — that is why the algorithm is called "gradient" boost.
Why residuals = the gradient
Squared loss: L = ½(y − F)²

Its negative gradient with respect to prediction F:
−∂L/∂F = y − F = the residual
Fitting each new tree to the residuals is exactly gradient descent in function space.
Formal algorithm (Friedman, 1999)
F₀
Initialize. Find the constant γ minimizing total loss. For squared loss this is the mean of y.
F₀(x) = argminᵧ Σ L(yᵢ, γ) = mean(y)
2-1
Compute pseudo-residuals for each sample at step m:
rᵢₘ = −∂L(yᵢ, Fₘ₋₁(xᵢ)) / ∂Fₘ₋₁(xᵢ) = yᵢ − Fₘ₋₁(xᵢ)
2-2
Fit a regression tree to the pseudo-residuals. This creates J terminal regions R₁ₘ … Rⱼₘ (leaves).
2-3
Find the optimal output value for each leaf j. For squared loss this is the average of residuals in that leaf:
γⱼₘ = mean { rᵢₘ : xᵢ ∈ Rⱼₘ }
2-4
Update the model. Add the new tree scaled by learning rate ν:
Fₘ(x) = Fₘ₋₁(x) + ν · Σⱼ γⱼₘ · 1(x ∈ Rⱼₘ)
Final combined prediction
F_M(x) = F₀(x) + ν·tree₁(x) + ν·tree₂(x) + … + ν·treeM(x)
The prediction accumulates contributions from all trees. Because each tree corrects what all previous ones got wrong, the model progressively improves. The sum converges to a strong learner from many weak learners.
Part 3 of 4
Gradient Boost for Classification — main ideas
Classification follows the same broad structure but works in log-odds space instead of raw value space. Predictions are then converted to probabilities via the logistic function.
Key differences from regression
Regression
Initial leaf = mean(y).
Residuals = y − predicted value.
Leaf output = average of residuals.
Classification
Initial leaf = log(odds).
Residuals = observed − predicted probability.
Leaf output uses a special formula.
Algorithm steps (classification)
1
Initialize with log(odds). Count positives and negatives. The initial prediction is:
log(odds) = log( #positives / #negatives )
Convert to probability: p = e^log(odds) / (1 + e^log(odds))
2
Compute pseudo-residuals. For binary classification with log-loss:
rᵢ = Observed − Predicted probability = yᵢ − pᵢ
These residuals range from −1 to +1.
3
Fit a regression tree to the residuals. Even though this is classification, residuals are continuous, so a regression tree is used. Limit leaves to 8–32.
4
Compute leaf output values using the special formula (because residuals and log-odds live in different spaces):
γⱼ = Σ residuals / Σ [pᵢ(1 − pᵢ)]
The denominator is the sum of predicted probability variances in that leaf.
5
Update log(odds) prediction:
log(odds)_new = log(odds)_old + ν × γⱼ
Convert to probability with the logistic function for the next residual calculation.
6
Repeat until max trees reached. The final class is determined by comparing the final probability to a threshold (usually 0.5).
Part 4 of 4
Classification — the math behind leaf values
Part 4 derives why the leaf output formula uses a second-order Taylor expansion. Predictions are in log-odds space, but residuals are in probability space — a direct average would be mathematically inconsistent.
The problem with plain averaging
In regression, the optimal leaf value is the mean of residuals — straightforward. In classification, residuals are probability-space quantities, but updates happen in log-odds space. We must find the γ that minimizes the log-loss for each leaf, not just average the residuals.
Deriving the leaf output formula
1
The loss function for classification is log-loss (binary cross-entropy):
L = −[y·log(p) + (1−y)·log(1−p)]
2
To find the γ (leaf output, added to log-odds) that minimizes this loss, take the second-order Taylor expansion around the current prediction and solve to get:
γⱼ = Σᵢ residuals / Σᵢ [pᵢ(1 − pᵢ)]
The denominator is the sum of predicted probability variances in that leaf.
3
Intuition. When pᵢ is near 0 or 1, the model is already confident — pᵢ(1−pᵢ) is small, so those samples get less influence. When pᵢ ≈ 0.5 (uncertain), pᵢ(1−pᵢ) ≈ 0.25, so uncertain samples pull harder on the update.
Full classification algorithm — summary
Step 1: F₀ = log(odds) = log(#pos / #neg) Step 2: rᵢ = yᵢ − sigmoid(Fₘ₋₁(xᵢ)) ← pseudo-residuals Step 3: Fit regression tree → leaves R₁…Rⱼ Step 4: γⱼ = Σ rᵢ / Σ [pᵢ(1−pᵢ)] ← leaf values Step 5: Fₘ = Fₘ₋₁ + ν · Σⱼ γⱼ · 1(x∈Rⱼ) ← update log-odds Step 6: p_final = sigmoid(F_M(x)) Step 7: class = 1 if p_final ≥ 0.5 else 0
Key insight: same structure, different loss
The overall Gradient Boost framework is identical for regression and classification. What changes is only the loss function and the resulting leaf-value formula. Swap in any differentiable loss and the algorithm still works — this generality is why libraries like XGBoost and LightGBM support so many problem types.
