AdaBoost, clearly explained

Adaptive Boosting builds a strong classifier from many weak decision stumps, iteratively focusing on the hardest examples.

The 3 core ideas
1. Forest of stumps, not full trees
AdaBoost uses decision stumps — trees with only one split. Each stump is a weak learner, slightly better than random guessing.
2. Stumps have different amounts of say
Unlike Random Forests (equal votes), each AdaBoost stump gets a weight called Amount of Say (α) based on accuracy. Better stumps influence the final answer more.
3. Stumps are made sequentially — errors inform the next
Each stump is built knowing what the previous one got wrong. Misclassified samples get higher weights so the next stump focuses on them.
Sequential boosting pipeline
Deep dives
Building the first stump — Gini impurity
AdaBoost evaluates all features and picks the stump with the lowest weighted Gini impurity as the first weak learner.
Gini = 1 − Σ(pᵢ)²
Gini = 0 → perfect purity (all same class)  |  Gini = 0.5 → max impurity (50/50 split)
✅ Correct: 3
❌ Wrong: 1
Gini = 0.375
Somewhat impure
The stump with the lowest weighted Gini impurity (using current sample weights) is selected each round.
Amount of Say (α) — stump influence weight
After building a stump, compute how much it should influence the final prediction:
α = ½ × log( (1 − Total Error) / Total Error )
Total Error = sum of weights of misclassified samples. On the first stump, all sample weights = 1/N.
Error: 0.30
α = 0.423
Good classifier — positive say
When error = 0.5 (random guessing), α = 0. When error > 0.5, α goes negative — AdaBoost flips the stump's predictions and still uses it!
Updating sample weights after each stump
Misclassified samples get higher weight; correctly classified get lower weight. Then all weights are normalized to sum to 1.
Misclassified: w_new = w × e^α  ↑ higher
Correct: w_new = w × e^(−α)  ↓ lower
α: 0.42
Normalization ensures weights always sum to 1, so they can serve as sampling probabilities when building the next stump.
Making the final prediction
Each stump votes for a class, weighted by α. The class with the highest total α-weighted votes wins.

Unlike a majority vote, a single highly-accurate stump (high α) can outweigh several mediocre ones.

AdaBoost is a boosting method — converts weak classifiers into one strong one. Random Forests use bagging to reduce variance of strong classifiers.
Full algorithm
1. Initialize: w = 1/N for all samples
2. Find best stump using weighted Gini
3. Compute Total Error = Σw of misclassified samples
4. Compute α = ½ log((1−ε)/ε)
5. Update weights: ↑ misclassified × e^α, ↓ correct × e^(−α)
6. Normalize all weights to sum to 1
7. Repeat from step 2 for T rounds
8. Final: sign(Σ αₜ × hₜ(x)) → class
Note: For Chest Pain stump, α = ½·log(5/3) ≈ 0.25 (not 0.42 — see video correction at 10:18)
