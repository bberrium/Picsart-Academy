Мотивация и постановка задачи

Введение

Центральное свойство

Ортогональные преобразования изометричны — не изменяют евклидову норму:

‖Ux‖₂² = x*U*Ux = x*x = ‖x‖₂²

Число обусловленности не ухудшается: κ(QA) = κ(A)

Вошёл в пакеты EISPACK, затем LAPACK

Сегодня

Основа NumPy, SciPy, MATLAB, Julia — везде, где вычисляют спектр

Унитарные и ортогональные матрицы

Теоретические основы
Определение 1

Матрица U ∈ ℂⁿˣⁿ называется унитарной, если:

U*U = UU* = E

В вещественном случае U ∈ ℝⁿˣⁿ — ортогональная: UᵀU = UUᵀ = E

Доказательство Утв. 1

Утв. 1. Произведение унитарных матриц — унитарная матрица.

(UV)*(UV) = V*U*UV = V*EV = V*V = E ✓
Утверждение 2

Собственные значения унитарной матрицы имеют модуль |λ| = 1

Доказательство
Ux = λx, x ≠ 0
⟹ ‖Ux‖₂ = |λ| ‖x‖₂
Но ‖Ux‖₂ = ‖x‖₂ (изометрия)
⟹ |λ| = 1 □

Ключевые свойства

  • det(U) = ±1
  • U⁻¹ = Uᵀ (обращение = транспонирование)
  • Сохраняет евклидову норму и скалярное произведение
  • Столбцы образуют ортонормированный базис

Матрица Хаусхолдера (отражения)

Теоретические основы
Определение 2

Пусть v ∈ ℝⁿ, v ≠ 0. Матрица Хаусхолдера:

H = E − 2vvᵀ / vᵀv

Геометрически: отражение ℝⁿ относительно гиперплоскости {x : vᵀx = 0}

Утверждение 3

H симметрична и инволютивна: H = Hᵀ, H² = E

Доказательство H² = E
H² = (E − 2vvᵀ/‖v‖²)²
= E − 4vvᵀ/‖v‖² + 4v(vᵀv)vᵀ/‖v‖⁴
= E □

Построение вектора отражения

Для данного x выбираем v так, чтобы Hx = αe₁, |α| = ‖x‖₂:

v = x + sign(x₁) ‖x‖₂ e₁

Выбор знака — численная устойчивость

Знак выбирается противоположным знаку x₁.

Если x₁ ≈ ‖x‖₂, при знаке «−» первая компонента v₁ = x₁ − ‖x‖₂ ≈ 0 — катастрофическая отмена. Противоположный знак гарантирует v₁ = x₁ + ‖x‖₂, что является сложением двух чисел одного знака.

Матрица Гивенса (вращения)

Теоретические основы
Определение 3

Матрица Гивенса G(i,j,θ) совпадает с E, за исключением:

gii = gjj = cos θ
gij = −sin θ, gji = sin θ

Gᵀ G = E — ортогональна. Умножение слева задаёт вращение в плоскости (i,j).

Обнуление элемента xⱼ

Хотим: (Gx)ⱼ = 0, (Gx)ᵢ = r. Вычисляем без арктангенса:

r = √(xᵢ² + xⱼ²)
cos θ = xᵢ/r, sin θ = xⱼ/r
[c s] [xᵢ] [r]
[−s c] [xⱼ] = [0]

Теорема существования QR-разложения

QR-разложение
Теорема 1 (QR-разложение)

Пусть A ∈ ℝᵐˣⁿ, m ≥ n. Тогда существуют ортогональная матрица Q ∈ ℝᵐˣᵐ и верхнетреугольная матрица R ∈ ℝᵐˣⁿ такие, что:

A = QR

Если rank A = n, разложение единственно при условии rii > 0.

Доказательство (индукция по n)
1
База n=1: A = a₁. Полагаем q₁ = a₁/‖a₁‖₂, дополняем до базиса ℝᵐ. Тогда A = QR при R = (‖a₁‖₂, 0,…,0)ᵀ.
2
Шаг: Пишем A = [a₁|B]. Выбираем H₁: H₁a₁ = r₁₁e₁. Тогда H₁A = (r₁₁ b̃ᵀ / 0 B̃).
3
Индукция: B̃ = Q̃R̃. Полагаем Q₁ = H₁ᵀ diag(1, Q̃), R = (r₁₁ b̃ᵀ / 0 R̃). Получаем A = Q₁R. □

Единственность

1
Допустим A = Q₁R₁ = Q₂R₂. Тогда Q₂ᵀQ₁ = R₂R₁⁻¹.
2
Левая часть — ортогональная; правая — верхнетреугольная. Такая матрица диагональна с элементами ±1.
3
При rii > 0: диагональ содержит только +1, то есть D = E. Следовательно Q₁ = Q₂, R₁ = R₂. □

Алгоритм Хаусхолдера

QR-разложение

Схема алгоритма (k = 1,…,n)

1
Извлечь подстолбец: x = A(k:m, k)
2
Вычислить: vₖ = x + sign(x₁)‖x‖₂e₁
3
Малое отражение: H̃ₖ = E − 2vₖvₖᵀ/vₖᵀvₖ
4
Встраивание: Hₖ = diag(Eₖ₋₁, H̃ₖ)
5
Обновить: A ← HₖA

Результат

Hₙ···H₁A = R
A = QR, Q = H₁···Hₙ

H²ₖ = E ⟹ H⁻¹ₖ = Hₖ — перенос тривиален

Вычислительная сложность

O(2mn² − ⅔n³) флопс

При m = n: ≈ 4/3 n³ — примерно вдвое дороже LU, зато абсолютно устойчиво

Неявное хранение Q (ключевая оптимизация)

Q явно не формируется. Векторы vₖ записываются в нули под диагональю A.

Hx = x − 2v(vᵀx)/vᵀv

Экономия: вместо m×m матрицы (до 8 ТБ при m=10⁶) — n векторов

Алгоритм Гивенса

QR-разложение

Схема алгоритма

1
Для каждого элемента aᵢⱼ, i > j (ниже диагонали)
2
Вычислить: r = √(a²ⱼⱼ + a²ᵢⱼ), c = aⱼⱼ/r, s = aᵢⱼ/r
3
Применить вращение G(j,i,θ) к строкам j и i матрицы
4
Накопить Q: Q ← Q · G(j,i,θ)ᵀ
Утверждение 4 (Результат)
Gₙ,ₙ₋₁ ··· G₂,₁ A = R
A = QR, Q = (Gₙ,ₙ₋₁ ··· G₂,₁)ᵀ

В отличие от H, матрица G несимметрична ⟹ обратная = транспонированная, а не сама матрица

Сложность и выводы

Плотная матрица O(3mn²) ≈ 1.5× дороже Хаусхолдера
Преимущество разреженных Каждое вращение изменяет только 2 строки ⟹ нет fill-in ⟹ структура нулей сохраняется
Практический вывод Хаусхолдер — стандарт для плотных матриц
Гивенс — оптимален для разреженных, ленточных матриц, инкрементальных обновлений

Базовый QR-алгоритм

QR-алгоритм

Итерационный процесс

Полагаем A₀ = A. На каждой итерации k = 0, 1, 2, …:

Aₖ = QₖRₖ (QR-разложение)
↓
Aₖ₊₁ = RₖQₖ (переставляем)
Утверждение 5: Сохранение спектра

Aₖ₊₁ подобна Aₖ — собственные значения не меняются

Доказательство
Aₖ = QₖRₖ ⟹ Rₖ = Qₖᵀ Aₖ
Aₖ₊₁ = RₖQₖ = Qₖᵀ AₖQₖ □

Следствие: σ(Aₖ) = σ(A) для всех k

Утверждение 6: Связь со степенями A

Aᵏ = Q̂ₖR̂ₖ, где:

Q̂ₖ = Q₁Q₂···Qₖ
R̂ₖ = RₖRₖ₋₁···R₁

QR-алгоритм — это ортогонализованный степенной метод. При k→∞ столбцы Q̂ₖ стремятся к собственным векторам A.

Сдвиги и ускорение сходимости

QR-алгоритм

QR-алгоритм со сдвигом μₖ

Aₖ − μₖE = QₖRₖ
Aₖ₊₁ = RₖQₖ + μₖE

Подобие сохраняется:

Aₖ₊₁ = Qₖᵀ(Aₖ−μₖE)Qₖ + μₖE = Qₖᵀ AₖQₖ □

Сдвиг Рэлея

μₖ = a⁽ᵏ⁾ₙₙ

Кубическая скорость сходимости:

|a⁽ᵏ⁺¹⁾ₙ,ₙ₋₁| = O(|a⁽ᵏ⁾ₙ,ₙ₋₁|³)

Число верных цифр утраивается на каждой итерации

Двойной сдвиг Фрэнсиса

Два сдвига μ и μ̄ за одну пару итераций для матриц с комплексно-сопряжёнными парами λ, λ̄.

Все вычисления остаются в ℝ — не требуется комплексная арифметика.

Теорема сходимости QR-алгоритма

QR-алгоритм
Теорема 2 (Сходимость QR-алгоритма)

Пусть A ∈ ℝⁿˣⁿ имеет собственные значения с попарно различными модулями:

|λ₁| > |λ₂| > ··· > |λₙ| > 0

Тогда Aₖ сходится к верхней треугольной форме Шура T, на диагонали которой стоят собственные значения A.

Схема доказательства
1
Из Утв.6: Aᵏ = Q̂ₖR̂ₖ. Пусть A = SΛS⁻¹, Λ = diag(λ₁,…,λₙ).
2
Тогда Aᵏ = SΛᵏS⁻¹. При k→∞:
3
|λᵢ/λᵢ₊₁|ᵏ → 0 (т.к. |λᵢ| > |λᵢ₊₁|) для всех i
4
Столбцы Q̂ₖ аппроксимируют инвариантные подпространства ⟹ Aₖ = Q̂ₖᵀ AQ̂ₖ → T □

Ключевой предел

|λᵢ / λᵢ₊₁|ᵏ → 0

Скорость сходимости субдиагональных элементов определяется отношением соседних собственных значений

Форма Шура

T = [λ₁ * * *]
    [0 λ₂ * *]
    [0 0 λ₃ *]
    [0 0 0 λₙ]

Практические оптимизации: форма Хессенберга

Оптимизация

Форма Хессенберга

Матрица «почти верхнетреугольная» — под диагональю только одна субдиагональ:

H = [* * * *]
    [* * * *]
    [0 * * *]
    [0 0 * *]

Приведение: n−2 преобразования Хаусхолдера. Стоимость: O(n³) — один раз

Ключевое свойство

Форма Хессенберга инвариантна при итерациях QR-алгоритма — достаточно привести один раз.

Сравнение сложности

ПодходСтоимость K итераций
Без ХессенбергаK · O(n³)
С ХессенбергомO(n³) + K · O(n²)

При K=50, n=1000: ускорение ~50 раз

Полная схема алгоритма

1. A ← UᵀAU (форма Хессенберга, O(n³))
2. while ‖aₙ,ₙ₋₁‖ > ε:
   2.1 Выбрать сдвиг μₖ
   2.2 Aₖ−μₖE = QₖRₖ (O(n²))
   2.3 Aₖ₊₁ = RₖQₖ+μₖE
   2.4 Дефляция при |aₙ,ₙ₋₁| < ε
3. Читаем λᵢ с диагонали T
