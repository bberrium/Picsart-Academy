# Computer Vision - Գործնական Դաս

Այս նյութը ամփոփում է **Computer Vision (CV)**-ի վերջին դասը, որից հետո հաջորդելու է **NLP** (Natural Language Processing) բաժինը։ Դասը ամբողջությամբ գործնական է և նվիրված է մեծ մոդելների հետ աշխատանքին։


## 1. Աշխատանքային Միջավայր. Ինչու՞ GPU և Google Colab

Քանի որ դասի ընթացքում աշխատելու ենք մեծ և ծավալուն մոդելների հետ, լոկալ համակարգչի **CPU**-ի (կենտրոնական պրոցեսոր) վրա աշխատելը կլինի չափազանց դանդաղ և անարդյունավետ։ Ժամանակ չկորցնելու համար աշխատանքը կատարվում է **Google Colab** միջավայրում՝ միանալով **GPU**-ին (գրաֆիկական պրոցեսոր), որն ապահովում է անհրաժեշտ արագություն։

  

## 2. Դասի Հիմնական Նպատակները

Դասի ընթացքում նախատեսվում է իրականացնել հետևյալ կետերը.

  

- **Pre-trained (նախապես մարզված) մոդելների կիրառում:** Սովորել, թե ինչպես վերցնել արդեն պատրաստի մոդելները և ուղղակի օգտագործել դրանք **classification** (դասակարգում) և **segmentation** (սեգմենտացիա) անելու համար։
    
      
    
- **Նոր խնդրի լուծում:** Կիրառել pre-trained **ResNet** մոդելը նոր խնդրի վրա։
    
      
    
- **YOLO մոդելի ուսումնասիրություն:** Հասկանալ, թե ինչ է YOLO-ն **output** անում, ոնց է աշխատում, և ինչ են նշանակում նրա պարամետրերը (օրինակ՝ _s s 5 b_ և այլն)։
    
      
    

## 3. Տնային Աշխատանք. UNet Արխիտեկտուրա

Դասի կարևորագույն հանձնարարություններից մեկը լինելու է **UNet** արխիտեկտուրայի զրոյից՝ ձեռքով գրելը։ Սա նախորդ **CNN** (Convolutional Neural Networks) դասերի գագաթնակետն է։

  

- **Բարդությունը:** UNet-ի դեպքում անընդհատ պետք է անել **downsampling** և **upsampling**։
    
      
    
- **Նպատակը:** Պետք է այնպես կառուցել շերտերը, որ չափողականությունները խիստ պահպանվեն և համընկնեն, ինչը տրիվիալ (հեշտ) գործ չէ։
    
      
    
- Եթե կարողանաք ճիշտ գրել այս արխիտեկտուրան, կնշանակի, որ դուք ամբողջությամբ **master** եք արել նեյրոնային ցանցերի չափողականությունների (dimensions) հետ աշխատանքը։

## 5. Classification ResNet-50-ի միջոցով (Քայլ առ Քայլ Կոդով)

Եթե մեր նպատակն է պարզապես որոշել, թե ինչ կա նկարի վրա (օրինակ՝ շունը տարբերել կատվից), մեզ պետք չէ նոր մոդել **train** անել։ Այս խնդիրը վաղուց լուծված է։ Մենք պարզապես վերցնում ենք պատրաստի արդյունքը։

  

### Քայլ 5.1: Քաշերի (Weights) ընտրություն և մոդելի բեռնում

`ResNet-50`-ը architecture-ն է՝ կառուցված **skip connections**-ներով և **convolutional layer**-ներով, որի վերջում դրված է **classification head**: Որպեսզի այն աշխատի, մեզ պետք են մարզված քաշերը (**weights**):

Կան տարբեր քաշեր (օրինակ 1000 class v1, v2 և այլն), բայց մենք վերցնում ենք `DEFAULT` տարբերակը, որն ավտոմատ ընտրում է դրանցից ամենալավը։

  
```python
import torch
from torchvision.models import resnet50, ResNet50_Weights

# 1. Վերցնում ենք ամենալավ (default) pre-trained weights-երը
weights = ResNet50_Weights.DEFAULT

# 2. Ստեղծում ենք մոդելը՝ փոխանցելով ընտրված քաշերը
model_cls = resnet50(weights=weights)

# 3. Տեղափոխում ենք մոդելը GPU-ի վրա արագ աշխատելու համար
model_cls = model_cls.to('cuda')
```

### Քայլ 5.2: Մոդելը դնել Evaluation Mode-ի

Քանի որ մենք չենք ուզում մարզել (train անել) մոդելը, այլ միայն ուզում ենք **կանխատեսում (evaluation/prediction)** անել, մենք պետք է անջատենք այնպիսի ֆունկցիաներ, ինչպիսիք են գրադիենտների track անելը, **batch normalization**-ը և **dropout**-ը։ Սա արվում է `.eval()` ֆունկցիայի միջոցով։

  

```python
# Դնում ենք evaluation mode, որպեսզի անջատվեն training-ին բնորոշ գործընթացները
model_cls.eval()
```

### Քայլ 5.3: Նկարի նախապատրաստում (Preprocessing) և Batch Dimension

Մոդելը չի կարող ընդունել ցանկացած նկար։ Այն սպասում է կոնկրետ չափողականության թենզորի (tensor): Բարեբախտաբար, `weights.transforms()`-ը պարունակում է բոլոր այն մաթեմատիկական և ֆորմատային ձևափոխությունները, որոնք պետք է արվեն նկարի հետ (օրինակ՝ եթե նկարը $1500 \times 1000$ է, preprocess-ը կսարքի այն $224 \times 224$, ինչպես ակնկալում է ResNet-ը)։

  

**ԿԱՐԵՎՈՐ ԿՈՆՑԵՊՏ - Batch Dimension (`unsqueeze` և `squeeze`)**

Նեյրոնային ցանցերը սովոր են աշխատել **mini-batch gradient descent**-ով, այսինքն՝ ոչ թե մեկ նկարի հետ են աշխատում, այլ նկարների խմբի (batch)։

  

- Նկարի ստանդարտ չափն է՝ **$C \times H \times W$** (Channels, Height, Width): Օրինակ՝ $3 \times 512 \times 512$ (որտեղ 3-ը RGB-ն է)։
    
      
    
- Մոդելը սպասում է 4-չափանի թենզոր՝ **$B \times C \times H \times W$** (որտեղ $B$-ն Batch size-ն է)։
    
      
    
- Եթե մենք ունենք ընդամենը 1 հատ նկար, մենք պետք է արհեստականորեն ավելացնենք այդ չափողականությունը զրոյական ինդեքսում։ Այս գործողությունը կոչվում է **unsqueeze(0)**: Այն նկարը սարքում է **$1 \times C \times H \times W$**:
    
      
    
- Հակառակ պրոցեսը (ավելորդ 1-երի վերացումը) կոչվում է **squeeze**:


### Ի՞նչու ենք սա անում — Վիզուալ բացատրություն

| Քայլ                      |                   |                    | Ժամանակ                           |
| ------------------------- | ----------------- | ------------------ | --------------------------------- |
| **Քայլ 1: Preprocess**    | `preprocess(img)` | `[3, 224, 224]`    | $C \times H \times W$ (batch չկա) |
| **Քայլ 2: unsqueeze(0)**  | `.unsqueeze(0)`   | `[1, 3, 224, 224]` | $B=1$ ավելացվել է **index 0**-ում |
| **Քայլ 3: Model forward** | `model(batch)`    | `[1, 1000]`        | Model-ը վերադարձնում է batch-ով   |
| **Քայլ 4: squeeze(0)**    | `.squeeze(0)`     | `[1000]`           | Batch dimension հեռացվել է        |

**Տեսե՛ք ինչ է լինում:**
```
unsqueeze(0)                    squeeze(0)
[3, 224, 224]  ───────►  [1, 3, 224, 224]  ─────►  [1000] (output-finales)
  (no batch)     model          (batch=1)           (clean 1D vector)
```

**Ի՞նչու index 0-ը:** PyTorch-ում **batch միշտ դիրք 0-ում է** (`dim=0`). Դրանով՝ `[B, C, H, W]`.

**Ի՞նչու անհրաժեշտ է squeeze(0)-ն output-ից հետո:**
```python
# Առանց squeeze (messy):
probabilities = F.softmax(prediction, dim=1)  # dim=1
predicted_class = probabilities.argmax(dim=1).item()  # tensor([42]) → .item()

# squeeze (clean):
prediction = prediction.squeeze(0)        # [1000]
probabilities = F.softmax(prediction, dim=0)  # dim=0
predicted_class = probabilities.argmax().item()  # clean integer
```

    

```python
# Վերցնում ենք մեր ընտրված քաշերին համապատասխանող preprocessing ֆունկցիան
preprocess = weights.transforms()

# Ենթադրենք ունենք 'img' (օրինակ՝ Շան նկարը PyTorch-ի դեմոներից)
# 1. Կիրառում ենք նախապատրաստումը
# 2. Ավելացնում ենք Batch չափողականություն զրոյական ինդեքսում (unsqueeze)
# 3. Տանում ենք GPU
batch = preprocess(img).unsqueeze(0).to('cuda') 
```

### Քայլ 5.4: Կանխատեսում (Forward Pass) Context Manager-ի միջոցով

Երբ մենք ուղղակի prediction ենք անում, մեզ պետք չէ հաշվել **գրադիենտները (gradients)**։ Գրադիենտները հաշվվում են միայն **backpropagation**-ի ժամանակ՝ քաշերը փոխելու նպատակով։ Հիշողություն խնայելու և արագացնելու համար օգտագործում ենք `with torch.no_grad():` **Context Manager**-ը։

  

> 💡 **Ինչ է Context Manager-ը:** Ինչպես Python-ում ֆայլեր կարդալիս գրում ենք `with open(...) as f:`, որպեսզի բլոկից դուրս գալուն պես ֆայլն ավտոմատ փակվի և համակարգը չծանրաբեռնվի, այնպես էլ `with torch.no_grad():`-ը նշանակում է, որ գրադիենտների հաշվարկը անջատված է միայն և բացառապես իր տակ գտնվող **տաբուլյացիայի (indentation)** ներսում: Բլոկից դուրս գալուն պես նորմալ աշխատանքը կվերականգնվի:
> 
>   

Մոդելը կանխատեսում անելիս վերադարձնում է ոչ թե հավանականություններ, այլ **logits** (մաքուր թվեր, որոնք դուրս են գալիս վերջին layer-ից): Դրանք տոկոսային հավանականությունների վերածելու համար պետք է կիրառել **Softmax**։

  

```python
# Context manager-ով անջատում ենք գրադիենտների հաշվարկը
with torch.no_grad():
    prediction = model_cls(batch) # Կատարում ենք forward pass

# 1. Քանի որ batch dimension-ը էլ պետք չէ (վերադարձել է 1xN չափով), հեռացնում ենք այն՝ squeeze(0)
prediction = prediction.squeeze(0)

# 2. Logits-ները վերածում ենք հավանականությունների Softmax-ի միջոցով (0 առանցքի երկայնքով)
probabilities = torch.nn.functional.softmax(prediction, dim=0)

# 3. argmax()-ի միջոցով գտնում ենք այն կլասի ինդեքսը, որն ունի ամենամեծ հավանականությունը
predicted_class = probabilities.argmax().item()
confidence = probabilities[predicted_class].item()

print(f"Հավանականություն: {confidence * 100:.1f}%")
```

- Եթե մենք շեմը իջեցնենք (օրինակ՝ > 0.2 կամ > 0), մոդելը ցույց կտա շատ այլ box-եր՝ օրինակ կատու (35% հավանականությամբ), այծ կամ ֆրիզբի:

- Հետաքրքիր փաստ. դասի օրինակում մոդելը շանը գտել էր երկու անգամ (մի անգամ 96%, մյուս անգամ ավելի ցածր), և **NMS (Non-Maximum Suppression)** ալգորիթմը չէր հեռացրել կրկնվող արդյունքը:
    
      
    

<mark style="background: #FFB8EBA6;">ԿՈԴԸ ԵՎ ՆՐԱ ԲԱՑԱՏՐՈՒԹՅՈՒՆԸ. Object Detection</mark> 

```python
# 2. OBJECT DETECTION
print("\n--- 2. Object Detection (Faster R-CNN) ---")

# 1. Վերցնում ենք ամենալավ (default) pre-trained weights-երը COCO v1 բազայի վրայից:
weights_det = FasterRCNN_ResNet50_FPN_Weights.DEFAULT

# 2. Ստեղծում ենք Faster R-CNN մոդելը և տանում GPU-ի վրա:
model_det = fasterrcnn_resnet50_fpn(weights=weights_det).to(device)

# 3. Դնում ենք evaluation mode (պարտադիր քայլ՝ կանխատեսում անելուց առաջ):
model_det.eval()

# 4. Նկարի նախապատրաստում: Preprocess ենք անում և ավելացնում batch dimension (unsqueeze(0)):
preprocess_det = weights_det.transforms()
batch_det = preprocess_det(img).unsqueeze(0).to(device)

# 5. Forward pass՝ անջատած գրադիենտներով:
with torch.no_grad():
    predictions = model_det(batch_det)[0] # Վերցնում ենք 0-րդ ինդեքսը, որպեսզի ազատվենք լիստից ու ստանանք բուն Dictionary-ն:

# --- ՎԻԶՈՒԱԼԻԶԱՑԻԱ ---
fig, ax = plt.subplots(1)
ax.imshow(img)

# 6. Ֆիլտրում և Նկարում. Անցնում ենք բոլոր գտնված bounding box-երով
for i in range(len(predictions['boxes'])):
    score = predictions['scores'][i].item() # Վերցնում ենք հավանականությունը
    
    if score > 0.8: # Thresholding. Պահում ենք միայն այն box-երը, որոնց վստահությունը 80%-ից բարձր է:
        # GPU-ի վրայի tensor-ը տեղափոխում ենք CPU, որպեսզի numpy-ը կարողանա աշխատել դրա հետ:
        box = predictions['boxes'][i].cpu().numpy() 
        label = weights_det.meta["categories"][predictions['labels'][i]] # Վերցնում ենք class-ի անվանումը

        # 7. Նկարում ենք ուղղանկյուն (Rectangle) տրված կոորդինատներով:
        rect = patches.Rectangle((box[0], box[1]), box[2]-box[0], box[3]-box[1], linewidth=2, edgecolor='r', facecolor='none')
        ax.add_patch(rect)
        ax.text(box[0], box[1]-5, f"{label}: {score:.2f}", color='red', weight='bold')

plt.axis('off')
plt.show()
```

## 2. Semantic Segmentation (Սեմանտիկ Սեգմենտացիա) FCN-ի միջոցով

Սեգմենտացիայի խնդրի համար օգտագործում ենք **FCN (Fully Convolutional Network)** մոդելը՝ դարձյալ ResNet50 backbone-ով:

  

### Չափողականությունների Խնդիրը և Interpolation-ի Կիրառումը

Սեգմենտացիան տարբերվում է նրանով, որ արդյունքում մենք պետք է ստանանք mask (դիմակ), որը կտեղադրենք նկարի վրա: Սակայն այստեղ ծագում է չափողականության (dimension) խնդիր:

  

- Երբ մենք նկարը փոխանցում ենք `preprocess()` ֆունկցիային, այն փոքրացնում է նկարը մոդելի համար հասկանալի ստանդարտ չափերի (որով այն train է եղել ImageNet-ի վրա):
    
      
    
- Ուստի, մոդելի վերադարձրած արդյունքը (output mask-ը) ավելի փոքր է և **չի համընկնում մեր օրիգինալ մեծ նկարի չափերի հետ**:
    
      
    
- Այս խնդիրը լուծելու համար մենք պետք է օգտագործենք **Bilinear Interpolation** (երկգծային ինտերպոլացիա), որի նպատակն է ստացված փոքր արդյունքի չափողականությունը մեծացնել ու դարձնել ճիշտ այնքան, ինչքան օրիգինալ նկարինն էր։
    
      
```
Original Image (512×512)
        │
        ▼ Preprocess (resize + normalize)
Model Input (224×224)
        │
        ▼ FCN-ResNet50 (stride 32 total downsampling)
Feature Map (7×7)  →  Logits (21×7×7)
        │
        ▼ Bilinear Interpolation (×73 upscale!)
Upsampled Logits (21×512×512)
        │
        ▼ argmax(0) → Class per pixel
Segmentation Mask (512×512)  ← Ready to overlay!
```

### Արդյունքը

FCN մոդելը շանը գտնում և սեգմենտացիա է անում բավականին լավ: Ճիշտ է, այն կարող է ինչ-որ փոքր դետալներ սխալ հասկանալ, օրինակ՝ շան պոչի հատվածում կարող է անհասկանալի բաներ կանխատեսել (օրինակ՝ փետուր, որովհետև պոչի մազերը նման են փետուրի), բայց ընդհանուր առմամբ արդյունքը շատ որակյալ է։


```python
print("\n--- 3. Semantic Segmentation (FCN) ---")

# 1. Մոդելի և քաշերի լոդինգ:
weights_seg = FCN_ResNet50_Weights.DEFAULT
model_seg = fcn_resnet50(weights=weights_seg).to(device)
model_seg.eval()

# 2. Նկարի նախապատրաստում:
preprocess_seg = weights_seg.transforms()
batch_seg = preprocess_seg(img).unsqueeze(0).to(device)

import torch.nn.functional as F

with torch.no_grad():
    # 3. Ստանում ենք raw logits: 
    # Արդյունքը կլինի [1, 21, H_resized, W_resized] ֆորմատով, որտեղ 21-ը class-ների քանակն է:
    output = model_seg(batch_seg)['out']

    # 4. UPSAMPLE: Քանի որ preprocess-ը փոքրացրել էր նկարը, մենք այստեղ ինտերպոլացիայի 
    # միջոցով վերականգնում ենք օրիգինալ նկարի չափողականությունը:
    output_resized = F.interpolate(output, size=(img.height, img.width), mode='bilinear', align_corners=False)

# 5. Output-ը այժմ ունի [21 classes, Original_Height, Original_Width] տեսք: 
# Մենք վերցնում ենք batch-ի 0-րդ ինդեքսը, ապա argmax ենք անում 0 առանցքով, որպեսզի ամեն պիքսելի համար
# գտնենք ամենահավանական class-ը:
# Եվ վերջապես, .cpu().numpy()-ով այն GPU-ից բերում ենք CPU-ի վրա որպեսզի նկարենք:
output_predictions = output_resized[0].argmax(0).cpu().numpy()

# --- ՎԻԶՈՒԱԼԻԶԱՑԻԱ ---
plt.imshow(img)
# Տեղադրում ենք սեգմենտացիայի mask-ը նկարի վրա: Alpha պարամետրը կիսաթափանցիկ է դարձնում այն:
plt.imshow(output_predictions, alpha=0.5, cmap='jet') 
plt.axis('off')
plt.title("Segmentation Mask")
plt.show()
```

**Վերջնական Ամփոփում:**

Ինչպես տեսանք, եթե ունենք պարզ ու հստակ խնդիրներ (ինչպես օրինակ՝ նկարում շուն գտնելը), pre-trained մոդելները մեզ ազատում են զրոյից մոդել կառուցելու և train անելու ծանր աշխատանքից։ Ցանկացած նորմալ ունիվերսալ մոդել պարտավոր է կարողանալ գոնե նման բազային կանխատեսումներ անել (ինչպես օրինակ շուն ճանաչելը), այլապես դրա արդյունավետությունը կասկածելի կլինի։

  

# Transfer Learning և Սինթետիկ Տվյալներ

Նախորդ օրինակներում մենք պարզապես վերցրեցինք նախապես մարզված (pre-trained) մոդելները և կիրառեցինք դրանք մեր նկարների վրա՝ ստանալով պատրաստի արդյունք: Բայց ի՞նչ անել, եթե մեր խնդիրը մի փոքր յուրահատուկ է, և գոյություն ունեցող մոդելը ուղիղ ձևով չի կարող այն լուծել: Այստեղ օգնության է հասնում **Transfer Learning**-ը (Փոխանցվող Ուսուցում)։

  

## 1. Խնդրի Դրվածքը. Սինթետիկ Տվյալներ (Synthetic Dataset)

Պատկերացնենք ունենք պարզագույն սինթետիկ **Dataset**: Դրանք սև ֆոնի (background) վրա նկարված սպիտակ կլորակներ (circles) են, որոնք գեներացվում են ռանդոմ (պատահական) կոորդինատներով և շառավիղներով:

  

Մեր նպատակն է օգտագործել **DeepLabV3** հզոր սեգմենտացիոն մոդելը (որը pre-trained է եղել բարդ նկարների վրա), որպեսզի այն սեգմենտացիա անի այս պարզ սպիտակ կլորակները:

  

- **Ինչու՞ անմիջապես չի աշխատի:** DeepLabV3-ը երբեք այսպիսի պարզ սև/սպիտակ սինթետիկ նկարներ չի տեսել: Ավելին, օրիգինալ մոդելը նախատեսված է **21 class** կանխատեսելու համար (մարդ, մեքենա, կենդանի և այլն), իսկ մեզ պետք է ընդամենը **2 class**՝ _Background (0)_ և _Circle (1)_:
    
      
    
- **Լուծում:** Մոդելը հաստատ ունի անհրաժեշտ "ունակությունները" (features) շրջանագծի եզրերը գտնելու համար, մենք պարզապես պետք է մի փոքր հարմարեցնենք այն մեր խնդրին՝ փոխելով վերջին շերտը և անելով Transfer Learning:
    
    

```python
import torch
import torch.nn as nn
import' torch.optim as optim
from torch.utils.data import Dataset, DataLoader
from torchvision.models.segmentation import deeplabv3_resnet50, DeepLabV3_ResNet50_Weights
from torchvision.models.segmentation.deeplabv3 import DeepLabHead
import numpy as np

# --- SYNTHETIC DATASET ---
# Ստեղծում ենք արագ dataset սև ֆոնի վրա սպիտակ շրջանագծերով, որպեսզի ինտերնետից ոչինչ չքաշենք:
class CircleDataset(Dataset):
    def __init__(self, num_samples=100, size=128):
        self.num_samples = num_samples
        self.size = size

    def __len__(self):
        return self.num_samples

    def __getitem__(self, idx):
        # Ստեղծում ենք սև նկար (zeros)
        img = np.zeros((self.size, self.size, 3), dtype=np.float32)
        mask = np.zeros((self.size, self.size), dtype=np.int64)

        # Գեներացնում ենք ռանդոմ շրջանագիծ
        radius = np.random.randint(10, 30)
        cx = np.random.randint(radius, self.size - radius) # Կենտրոնի X
        cy = np.random.randint(radius, self.size - radius) # Կենտրոնի Y

        y, x = np.ogrid[:self.size, :self.size]
        dist_from_center = np.sqrt((x - cx)**2 + (y - cy)**2)

        # 1 = Circle, 0 = Background
        circle_area = dist_from_center <= radius
        img[circle_area] = [1.0, 1.0, 1.0] # Շրջանագծի ներսը դարձնում ենք սպիտակ [1,1,1]
        mask[circle_area] = 1              # Class 1-ի համար դիմակ (mask)

        # Ձևափոխում ենք PyTorch tensor-ների: Ֆորմատը պետք է լինի [C, H, W] (Channels, Height, Width)
        img = torch.tensor(img).permute(2, 0, 1)
        mask = torch.tensor(mask)
        return img, mask

train_loader = DataLoader(CircleDataset(num_samples=64), batch_size=8, shuffle=True)
print("Synthetic Dataset Ready!")
```

## 2. Transfer Learning-ի Իրականացումը (Քայլ առ Քայլ)

Transfer Learning-ի հիմնական գաղափարն այն է, որ մենք վերցնում ենք հզոր մոդելի արդեն սովորած գիտելիքը (feature extraction մասը) և թարմացնում ենք միայն վերջին շերտերը նոր խնդրի համար։

  

### Քայլ 1: Բազային Մոդելի բեռնում (Load Pre-trained Model)

Վերցնում ենք DeepLabV3-ի արխիտեկտուրան (հիմքում ResNet50) և նրա default քաշերը (weights):

  

### Քայլ 2: Backbone-ի Սառեցում (Freezing the Backbone)

Մոդելը բաղկացած է երկու հիմնական մասից՝

  

1. **Backbone (Feature Extractor)**. Սա ResNet արխիտեկտուրան է, որը հասկանում է, թե ինչ են անկյունները, գույները, ձևերը: Այն արդեն շատ լավ մարզված է, և մենք **չենք ուզում** կորցնել նրա գիտելիքը կամ ժամանակ ծախսել այն նորից մարզելու վրա։
    
      
    
2. **Լուծում (Freeze):** Մենք անցնում ենք Backbone-ի բոլոր պարամետրերի վրայով և `requires_grad = False` ենք դնում:
    
      
    - _Ի՞նչ է սա նշանակում:_ Սա ասում է PyTorch-ին, որ այս պարամետրերի համար **gradients (ածանցյալներ)** չհաշվի։ Եթե ածանցյալ չկա, ուրեմն **back propagation** չի արվելու, և այս շերտերի քաշերը մնալու են անփոփոխ (սառեցված):
        
          
        

### Քայլ 3: Head-ի (Վերջնական Շերտի) Փոխարինումը

Օրիգինալ մոդելի `classifier` (կամ հաճախ անվանում են **head**) մասը սպասում է 21 class: Մենք այն ջնջում ենք և տեղադրում ենք նոր, մաքուր (չմարզված) `DeepLabHead`:

  

- Մուտքային պարամետրեր՝ 2048 (ResNet-ից եկող feature-ների չափը):
    
      
    
- Ելքային պարամետրեր՝ **2** (մեր 2 class-ները՝ Background և Circle):
    
      
    
- Քանի որ այս նոր head-ը մենք նոր ենք ստեղծել, դրա `requires_grad`-ը ավտոմատ `True` է, այսինքն՝ այն կմարզվի։
    
      
    

### Քայլ 4: Optimizer-ի Կարգավորումը և Պարամետրերի Կրճատումը

Մենք ստեղծում ենք **Adam Optimizer**, բայց նրան չենք տալիս մոդելի _բոլոր_ պարամետրերը։ Մենք նրան փոխանցում ենք `filter`-ված ցուցակ՝ միայն այն պարամետրերը, որոնց `requires_grad == True` (այսինքն՝ միայն մեր նոր ստեղծած head-ը):

  

- **Հսկայական առավելություն:** Օրիգինալ մոդելն ուներ մոտ **41 միլիոն պարամետր**: Շնորհիվ սառեցման (freeze), Optimizer-ը ստիպված է աշխատել ընդամենը **~18 միլիոն պարամետրի** հետ: Մենք ավելի քան կրկնակի կրճատեցինք մարզվող (trainable) պարամետրերի քանակը, ինչը կբերի շատ ավելի արագ և թեթև ուսուցման:
    
      
    

```python
# --- TRANSFER LEARNING SETUP ---

# 1. Վերցնում ենք Pre-trained DeepLabV3 մոդելը
weights = DeepLabV3_ResNet50_Weights.DEFAULT
model_seg_transfer = deeplabv3_resnet50(weights=weights)

# 2. FREEZE THE BACKBONE (Սառեցնում ենք հիմքը)
# Ասում ենք PyTorch-ին որ Backprop չանի և գրադիենտներ չհաշվի բարդ ResNet հատվածի համար
for param in model_seg_transfer.backbone.parameters():
    param.requires_grad = False

# 3. REPLACE THE HEAD (Փոխում ենք վերջնական դասակարգիչը)
# Օրիգինալը ունի 21 կլաս, մենք փոխարինում ենք այն նորով, որն ունի ընդամենը 2 (2048 input, 2 output):
model_seg_transfer.classifier = DeepLabHead(2048, 2)

# Տեղափոխում ենք մոդելը GPU
model_seg_transfer = model_seg_transfer.to('cuda')

# 4. OPTIMIZER
# ՈՒՇԱԴՐՈՒԹՅՈՒՆ. Optimizer-ին տալիս ենք ՄԻԱՅՆ այն պարամետրերը, որոնք ունեն requires_grad=True
optimizer = optim.Adam(filter(lambda p: p.requires_grad, model_seg_transfer.parameters()), lr=0.001)

# Սահմանում ենք կորստի ֆունկցիան (Loss function)
criterion = nn.CrossEntropyLoss()

print(f"Ընդհանուր պարամետրեր: {sum(p.numel() for p in model_seg_transfer.parameters())}")
print(f"Մարզվող պարամետրեր (միայն Head-ը): {sum(p.numel() for p in model_seg_transfer.parameters() if p.requires_grad)}")
```

## 3. Training Loop-ի Կառուցումը (Հանձնարարություն)

Ձեր առաջադրանքն է այս ձևափոխված մոդելի համար գրել **Training Loop**:

Թեև մենք արել ենք Transfer Learning, Loop-ի կառուցվածքը մնում է նույնը (PyTorch-ը լավություն է անում մեզ և ավտոմատ անտեսում է սառեցված շերտերը): Դուք պետք է գրեք դասական ցիկլ, որտեղ անում եք.

  

1. Վերցնում եք `batch`-ը (նկարները և mask-երը):
    
      
    
2. Անում եք **Forward pass** մոդելի միջով:
    
      
    
3. Հաշվում եք **Loss**-ը (criterion):
    
      
    
4. Զրոյացնում եք նախորդ քայլի գրադիենտները (`optimizer.zero_grad()`):
    
      
    
5. Անում եք **Back propagation** (`loss.backward()`):
    
6. Թարմացնում եք քաշերը (`optimizer.step()`):
    
      
    
    

### Key Components Explained

#### **`DataLoader` — Batched, Shuffled, Parallel Data Loading**
```python
from torch.utils.data import DataLoader

dataloader = DataLoader(
    dataset,           # Your Dataset object (implements __len__, __getitem__)
    batch_size=32,     # Samples per batch
    shuffle=True,      # Randomize order each epoch (critical for SGD)
    num_workers=4,     # Parallel CPU processes for loading/preprocessing
    pin_memory=True,   # Faster GPU transfer (CUDA only)
    drop_last=False    # Keep incomplete final batch
)
```

| Feature | Why It Matters |
|---------|----------------|
| **Batching** | Stacks samples → `[B, C, H, W]` tensor for vectorized GPU compute |
| **Shuffling** | Breaks correlation between consecutive samples → better gradient estimates |
| **`num_workers > 0`** | CPU loads/augments next batch while GPU trains current one (no GPU idle time) |
| **`pin_memory`** | Allocates in page-locked RAM → faster `to('cuda')` transfers |

**Iteration protocol:**
```python
for x, y in dataloader:  # x = [B, C, H, W], y = [B] or [B, H, W]
    x, y = x.to(device), y.to(device)
    ...
```

---

#### **`criterion` (Loss Function) — Measures "How Wrong" the Model Is**
```python
# Common choices:
criterion = nn.CrossEntropyLoss()           # Classification (logits + class indices)
criterion = nn.BCEWithLogitsLoss()          # Binary / multi-label (logits + 0/1 targets)
criterion = nn.MSELoss()                    # Regression (predicted + continuous targets)
criterion = nn.CrossEntropyLoss(ignore_index=255)  # Segmentation (ignore void pixels)
```

**What it does:**
```python
# Input: pred = [B, num_classes] (raw logits), target = [B] (class indices 0..C-1)
loss = criterion(pred, target)  # Returns scalar tensor (mean loss over batch)
```

| Loss | Use Case | Input Shapes |
|------|----------|--------------|
| `CrossEntropyLoss` | Multi-class classification | `pred: [B, C]`, `target: [B]` |
| `BCEWithLogitsLoss` | Multi-label / binary | `pred: [B, C]`, `target: [B, C]` (0/1) |
| `MSELoss` | Regression | `pred: [B, ...]`, `target: [B, ...]` |

**Key point:** `CrossEntropyLoss` combines `LogSoftmax` + `NLLLoss` internally — **pass raw logits, not probabilities**.

---

#### **Complete Training Loop with Annotations**
```python
for epoch in range(epochs):
    model.train()                    # Enable dropout, BN updates
    for x, y in dataloader:          # DataLoader yields batched (x, y)
        x, y = x.to(device), y.to(device)
        
        # 1. Forward pass
        pred = model(x)              # [B, num_classes] logits
        
        # 2. Compute loss (criterion)
        loss = criterion(pred, y)    # Scalar: mean loss over batch
        
        # 3. Zero gradients (fresh slate)
        optimizer.zero_grad(set_to_none=True)
        
        # 4. Backward pass
        loss.backward()              # Computes ∂loss/∂w for all parameters
        
        # 5. Update weights
        optimizer.step()             # w = w - lr * w.grad
```

## 1. YOLO-ի Մաթեմատիկական և Ճարտարապետական Հիմունքները

### YOLOv1-ի Հիմնական Գաղափարը ($S \times S \times (B \cdot 5 + C)$)

YOLO-ն Real-Time Object Detection-ի առաջատար արխիտեկտուրաներից է: Ի տարբերություն երկփուլանի (Two-Stage) մոդելների (ինչպիսին է R-CNN-ը), YOLO-ն նկարին նայում է **ընդամենը մեկ անգամ** (You Only Look Once) և անմիջապես կանխատեսում է և՛ Bounding Box-երի կոորդինատները, և՛ դրանց դասերը (classes):

1. **Grid:** Նկարը բաժանվում է $S \times S$ պարզ ցանցի (օրինակ՝ $7 \times 7$, $20 \times 20$):
2. **Responsibility:** Այն grid cell-ը (վանդակը), որի մեջ ընկնում է օբյեկտի **կենտրոնը**, պատասխանատու է այդ օբյեկտը դետեկտ (կանխատեսելու) անելու համար:
3. **Bounding Boxes ($B$):** Յուրաքանչյուր cell կանխատեսում է $B$ հատ Bounding Box:
4. **Վեկտորի Չափայնությունը ($5 + C$):** Յուրաքանչյուր Bounding Box-ի համար մոդելը կանխատեսում է **5 թիվ**.
* $x, y$ (կենտրոնի կոորդինատները relative grid-ի նկատմամբ)
* $w, h$ (լայնություն և բարձրություն relative ամբողջ նկարի նկատմամբ)
* $p_o$ (Confidence score / Objectness score – որքանով է վստահ, որ այդտեղ առհասարակ օբյեկտ կա)
* **$C$ հատ class probabilities** (եթե օբյեկտը կա, ապա COCO dataset-ի 80 class-ներից որին է պատկանում):

### 📦 What is NMS (Non-Maximum Suppression)?

**The Problem:** Object detectors predict **many overlapping boxes** for the same object.
Image with one dog:
```
┌─────────────────────────────────┐
│  ████████  ████████  ████████   │  ← 3 boxes, all covering the dog
│  █ Dog █   █ Dog  █  █ Dog  █   │     Confidences: 0.92, 0.87, 0.73
│  ████████  ████████  ████████   │
└─────────────────────────────────┘
```
One dog → 3 boxes with confidences: 0.92, 0.87, 0.73
All covering roughly the same region

**NMS Algorithm (per class):**
1. Sort all boxes by confidence (highest first)
2. Take highest-confidence box → **keep it**
3. For each remaining box:
   - If **IoU(kept_box, current_box) > threshold** (typically 0.5): **DISCARD** (duplicate)
4. Repeat until no boxes left

**IoU (Intersection over Union):**

IoU = Area(Intersection) / Area(Union)
```   ┌─────────┐
      │   A     │
  ┌───┼────┐    │
  │ B │####│    │  ← Intersection = ####
  │   │####│    │
  └───┼────┘    │
      │         │
      └─────────┘
```

IoU = 1.0  → Perfect overlap (same box)
IoU = 0.0  → No overlap
IoU > 0.5  → "Same object" (typical NMS threshold)

**Why RAW Output Here?**
TorchVision/YOLO models apply NMS **internally by default**. Accessing raw output (before internal NMS) allows:
- Custom NMS thresholds (0.3 for recall, 0.7 for precision)
- Soft-NMS (reduce scores instead of hard discard)
- Per-class NMS with different thresholds
- Ensemble: combine boxes from multiple models before NMS

**NMS Variants:**

| Variant        | Behavior                                    |
| -------------- | ------------------------------------------- |
| Standard       | Hard discard if IoU > thresh                |
| Soft-NMS       | `score *= exp(-IoU²/σ)` — better for crowds |
| Class-aware    | NMS per class separately (default)          |
| Class-agnostic | NMS across all classes                      |


> **One-liner:** NMS = "Keep the most confident box, delete its overlapping clones."

| **Index** | **Meaning**                           | **Count** |
| --------- | ------------------------------------- | --------- |
| **0**     | tx (x offset from cell left)          | 1         |

## Why Indices 24000–25200? — The Memory Layout
### The Flat Tensor: `[1, 25200, 85]`

YOLOv5 concatenates **all 3 grid scales** into one flat list of 25,200 predictions. The order is **fixed by the model architecture**:
```
Indices 0–25200:
┌────────────────────────────────────────────────────────────────────────┐
│ 0 ............... 4799   4800 ........ 20399        24000 .. 25199     │
│ └──────────┬──────────┘ └────────────┬────────────┘ └───┬─────────┘    │
│   80×80 grid (small)          40×40 grid (med)      20×20 grid (large) │
│     19,200 preds                 4,800 preds         1,200 preds       │
└────────────────────────────────────────────────────────────────────────┘
```

Why This Order? (Small → Medium → Large)
```
Backbone (ResNet/CSPDarknet)
        │
        ▼
    ┌─────────┐
    │  P3     │  ← 80×80 (small objects, high res)
    └────┬────┘
         │ upsample + concat
    ┌────┴────┐
    │  P4     │  ← 40×40 (medium objects)
    └────┬────┘
         │ upsample + concat
    ┌────┴────┐
    │  P5     │  ← 20×20 (large objects, low res)
    └─────────┘
        │
        ▼
Detection Heads (3 separate heads, one per scale)
        │
        ▼
Concat: [P3_head, P4_head, P5_head]  →  [19200, 4800, 1200] = 25200
```

In the Code
```python
# inference_out shape: [1, 25200, 85]
#                          │      │
#                          │      └── 85 features per prediction
#                          └─────── 25,200 total predictions (flat)

# Extract ONLY large-object grid (20×20):
grid_20 = inference_out[:, 24000:25200, :]  # [1, 1200, 85]

# Reshape to structured: [Batch, Anchors, Grid_Y, Grid_X, Features]
grid_20 = grid_20.view(1, 3, 20, 20, 85)
```

If You Wanted Other Scales

**`argmax()` needs a tensor to find the global maximum.** By extracting only the objectness scores (index 4), we get a clean `[3, 20, 20]` tensor where:

- **Every element = "How confident am I that an object exists here?"**
- **`argmax()` finds the single most confident (anchor, row, col) triplet**

## 3. CIFAR-10 Բոնուսային Առաջադրանք. Հասնել >95% Accuracy-ի

Տնային աշխատանքում զրոյից գրված CNN-ը CIFAR-10-ի վրա ապահովում էր մոտ **70-75%** accuracy: Օգտագործելով **ResNet18 Pre-trained մոդելը** և Transfer Learning տեխնիկան՝ մենք կարող ենք ընդամենը 1-2 epoch-ում հասնել **95%+ accuracy-ի**։

### Կարևոր Քայլեր.

1. **Resize (224x224):** CIFAR-10-ի նկարները $32 \times 32$ են, իսկ ImageNet-ի վրա մարզված ResNet18-ը սպասում է առնվազն $224 \times 224$ չափս:
2. **Normalization:** ImageNet-ի ստանդարտ mean/std parameters:
* `mean = [0.485, 0.456, 0.406]`
* `std = [0.229, 0.224, 0.225]`


3. **Model Surgery:** Freeze ենք անում backbone-ը, իսկ վերջին `model.fc` (Fully Connected) շերտը փոխարինում ենք 10 outputs ունեցող Linear շերտով:

CIFAR-10 Redemption (Ամբողջական Լուծում)
```python
import torch
import torch.nn as nn
import torch.optim as optim
import torchvision
import torchvision.transforms as T
from torchvision.models import resnet18, ResNet18_Weights
from torch.utils.data import DataLoader

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# 1. Transforms (Resize -> Tensor -> Normalize)
cifar_transform = T.Compose([
    T.Resize((224, 224)),
    T.ToTensor(),
    T.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
])

# 2. Datasets & DataLoaders
print("Loading CIFAR-10 dataset...")
train_dataset = torchvision.datasets.CIFAR10(root='./data', train=True, download=True, transform=cifar_transform)
val_dataset = torchvision.datasets.CIFAR10(root='./data', train=False, download=True, transform=cifar_transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True, num_workers=2)
val_loader = DataLoader(val_dataset, batch_size=64, shuffle=False, num_workers=2)

# 3. Model Surgery
weights = ResNet18_Weights.DEFAULT
model_cifar = resnet18(weights=weights)

# Freeze Feature Extractor (Backbone)
for param in model_cifar.parameters():
    param.requires_grad = False

# Replace FC Head for 10 CIFAR classes
in_features = model_cifar.fc.in_features
model_cifar.fc = nn.Linear(in_features, 10) # require_grad-ը ավտոմատ True է

model_cifar = model_cifar.to(device)

# 4. Loss & Optimizer (Միայն FC շերտի պարամետրերն ենք փոխանցում)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model_cifar.fc.parameters(), lr=0.001)

# 5. Train & Validation Loop
epochs = 1

for epoch in range(epochs):
    model_cifar.train()
    running_loss = 0.0
    
    for i, (inputs, labels) in enumerate(train_loader):
        inputs, labels = inputs.to(device), labels.to(device)
        
        optimizer.zero_grad()
        outputs = model_cifar(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item()
        if (i + 1) % 100 == 0:
            print(f"Epoch [{epoch+1}/{epochs}], Step [{i+1}/{len(train_loader)}], Loss: {running_loss/100:.4f}")
            running_loss = 0.0

    # Validation Pass
    model_cifar.eval()
    correct = 0
    total = 0
    with torch.no_grad():
        for inputs, labels in val_loader:
            inputs, labels = inputs.to(device), labels.to(device)
            outputs = model_cifar(inputs)
            _, predicted = torch.max(outputs.data, 1)
            total += labels.size(0)
            correct += (predicted == labels).sum().item()

    accuracy = 100 * correct / total
    print(f"\n Validation Accuracy: {accuracy:.2f}%\n")

```

## 4. Առաջիկա Տնային Աշխատանքների Կառուցվածքը

Տնային աշխատանքը բաղկացած է լինելու **երկու հիմնական մասից**.

### Մաս 1: U-Net Արխիտեկտուրայի Ստեղծում (Ձեռքով)

* **Նպատակը:** Զրոյից գրել U-Net-ի ամբողջական կոդը PyTorch-ով:
* **Կառուցվածքը:**
* **Contracting Path (Encoder):** Conv2D, BatchNorm, ReLU և MaxPool (Downsampling):
* **Bottleneck:** Ամենախորը շերտը:
* **Expanding Path (Decoder):** Transpose Convolution (`nn.ConvTranspose2d`) (Upsampling):
* **Skip Connections:** Encoder-ից ստացված Feature Map-երի կոնկատենացիան Decoder-ի համապատասխան շերտերի հետ (Tensor Shapes debugging-ի հմտությունների զարգացման համար):



### Մաս 2: YOLO Fine-Tuning և Video Detection

* **Նպատակը:** Վերցնել COCO 80-կլասների վրա pre-trained YOLOv5/v8 մոդելը, unfreeze անել վերջին շերտերը, fine-tune անել փոքր customized dataset-ի վրա:
